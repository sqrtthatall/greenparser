Политика конфиденциальности сервиса «GreenParser»

1. Общие положения

Настоящая Политика регламентирует обработку технической информации Telegram-ботом @greenparser_by_bot («Сервис»). Сервис предоставляет функции автоматизированного анализа общедоступных объявлений торговой площадки kufar.by.

2. Собираемые данные

Сервис собирает и хранит исключительно минимальный технический набор данных, необходимый для предоставления услуги:

  • Уникальный идентификатор Telegram (Telegram User ID) и никнейм (username);
  • Поисковые URL-ссылки и фильтры минус-слов, добавленные пользователем;
  • Идентификаторы супергрупп Telegram (в случае использования тарифа Business).

3. Платежные и банковские данные

Сервис не запрашивает, не обрабатывает и не хранит реквизиты банковских карт. Все транзакции осуществляются непосредственно через защищенную инфраструктуру мессенджера Telegram (Telegram Stars) либо через сертифицированных провайдеров платежей. Серверная часть бота получает лишь цифровой статус подтверждения оплаты.

4. Использование данных

Информация используется строго для передачи push-уведомлений о появлении новых объявлений согласно персональным фильтрам пользователя. Данные ни при каких обстоятельствах не передаются третьим лицам.

5. Отказ от аффилированности

Сервис «GreenParser» является независимым инструментом мониторинга и не связан, не спонсируется и не аффилирован с торговой площадкой Kufar или ее владельцами (Adevinta / ООО «Куфар»). Все товарные знаки принадлежат их правообладателям.

6. Удаление данных

Пользователь вправе удалить все свои поисковые ссылки и данные в любой момент, отправив команду останова / сброса настроек непосредственно в диалоге с @greenparser_by_bot.
